# Blush & Bloom 🌸💗

A tiny, interactive romantic website crafted to make someone special smile, blush, and feel appreciated.

## Features ✨

- **Charming Chibi Illustrations**: Handcrafted animations featuring blushing pandas, cute teddy bears, and sweet dolls.
- **Interactive Love Story**: Playful question cards with an elusive dodging button and thoughtful reflections.
- **Floral Bouquet Reveal**: An illustrated pastel bouquet arrangement of roses, tulips, and lavender.
- **Ambient Romantic Synthesizer**: Web Audio API music box melodies and gentle chime interactions.
- **Pastel Visual Design**: Built with Tailwind CSS and Framer Motion for responsive, fluid micro-interactions.

## Tech Stack 🛠️

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Kawaii Aesthetic System
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Celebration**: Canvas Confetti
- **Audio**: Web Audio API (zero external sound dependencies)

## Getting Started 🚀

### Prerequisites
Node.js (v18+)

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
